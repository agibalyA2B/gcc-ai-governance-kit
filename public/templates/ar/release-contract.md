# عقد إطلاق الذكاء الاصطناعي

اتفق على هذا العقد كتابياً قبل بدء إعادة التشغيل، عقداً لكل إجراء أو مجموعة إجراءات، حتى لا تتغير المعايير لاحقاً. حدّد حدّاً لكل بُعد من أبعاد الأدلة، ثم سجّل الأدلة والنتيجة. النجاح يعني أن الأدلة كافية لهذا التفويض المحدود، ولا يعني أبداً أن النظام ثبتت سلامته. راجع دليل سلّم الإطلاق.

## أبعاد الأدلة

| أبعاد الأدلة | الأدلة المطلوبة | الحدّ المتفق عليه | مرجع الدليل | النتيجة |
| --- | --- | --- | --- | --- |
| جودة القرار | الدقة مقارنة بنتائج مرجعية فُصل فيها بشكل مستقل |  |  |  |
| الإخفاقات الحرجة | لا نمط إخفاق مصنّف غير مقبول دون معالجة |  |  |  |
| التغطية | أدلة كافية عبر أنواع الحالات والحالات الطرفية والفئات المعنية |  |  |  |
| الموثوقية التشغيلية | سلوك مقبول عند تعطل الأدوات ونقص البيانات وانتهاء المهلة وإعادة المحاولة |  |  |  |
| الإشراف البشري | يستطيع الموظفون اكتشاف الأخطاء وتصحيحها حيثما يلزم الإشراف |  |  |  |
| الأمن والصلاحيات | صلاحيات متحقق منها، وحدود للإجراءات، وسجلات تدقيق، وضبط للوصول |  |  |  |
| الأساس القانوني والإجرائي | اعتماد الدور المفوَّض وترتيبات المساءلة |  |  |  |
| الضبط المستمر | المراقبة، واكتشاف الانحراف، ومعالجة الحوادث، والتعليق والاستعادة |  |  |  |

## سؤال بوابة الإطلاق

| البند | الإجابة |
| --- | --- |
| ما الذي يُخوَّل النظام تحديداً أن يقرره أو يفعله؟ |  |
| ما الأدلة التي تُظهر أن أداءه كافٍ؟ |  |
| ما الإخفاقات غير المقبولة مهما كان متوسط الأداء؟ |  |
| ما الحالات التي يجب أن تُحال دائماً إلى إنسان؟ |  |
| من يقبل المخاطر المتبقية ويعتمد الإطلاق؟ |  |
| ما الأدلة التي تستوجب تعليق الاستقلالية أو سحبها؟ |  |
